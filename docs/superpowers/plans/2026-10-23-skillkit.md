# skillkit (skill-health + skill-compat) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two user-invoked skills in the `l3east` plugin: `skill-health` audits every skill, command, hook and MCP server loaded on this machine; `skill-compat <candidate>` judges one new skill or plugin against that set before it is installed. Both share one deterministic toolbox (`scripts/skillkit/`) and one set of reference docs.

**Architecture:** Five small Python scripts (stdlib only, run with `python3 -I`) turn disk state and transcripts into JSON: inventory, usage, hooks/MCP merge (secrets masked), keyword clustering, description lint. A `run.sh` wrapper runs them in order. The two `SKILL.md` files are thin flows: run the scripts, dispatch one zero-context subagent per cluster for semantic verdicts, fill a report template, propose a `## Skill routing` block, then stop and wait for the user. No script or skill edits CLAUDE.md, settings, or installs anything on its own.

**Tech Stack:** Python 3 stdlib (`json`, `re`, `pathlib`, `subprocess`, `unittest`), bash 3.2-compatible shell, Claude Code plugin layout (`skills/<name>/SKILL.md`, `.claude-plugin/plugin.json`).

**Spec:** `docs/superpowers/specs/2026-10-23-skillkit-design.md`

## Global Constraints

- Scripts run as `python3 -I <script>` (isolated mode): the script dir is not on `sys.path`, so every script re-adds its own directory before `import common`. No third-party imports.
- Every script takes explicit paths (`--project`, `--claude-home`, `--out`); none reads `cwd` implicitly.
- Any value under an `env` or `headers` key, and any key matching `token|secret|password|api[-_]?key|authorization|private[-_]?key`, is replaced by `***` before it is written anywhere. Tests assert the fixture token string never appears in output.
- `claude plugin list --json` is the plugin source of truth; `--plugin-list <file>` overrides it for tests; cache scan is the fallback with `enabled: "unknown"`.
- Description limit copied from docs: 1,536 characters (`description` + `when_to_use`). Token estimate = `ceil(chars / 4)` and is labeled an estimate everywhere.
- Both skills set `disable-model-invocation: true`. They are reached as `/l3east:skill-health` and `/l3east:skill-compat`.
- Skills never run anything inside a candidate directory; candidate files are read as text.
- Commit messages are English. Never add a `Co-Authored-By` or `Generated with Claude Code` line (user's global rule).
- macOS default bash is 3.2: expand possibly-empty arrays as `${ARR[@]+"${ARR[@]}"}`.
- Test command for the whole suite: `python3 -m unittest discover -s tests/skillkit -t . -p 'test_*.py' -v` run from the repo root.

```python
"""Shared helpers for skillkit scripts.

Scripts run under `python3 -I`, so each one inserts its own directory into
sys.path before `import common`.
"""
from __future__ import annotations

import json
import math
import os
import re
import subprocess
from pathlib import Path

MASK = "***"
DESC_LIMIT = 1536
SECRET_KEY_RE = re.compile(r"(?i)(token|secret|passw(?:or)?d|api[-_]?key|authorization|private[-_]?key)")
SECRET_VALUE_RE = re.compile(r"^[A-Za-z0-9_\-=+]{32,}$")


def claude_home() -> Path:
    return Path(os.environ.get("CLAUDE_CONFIG_DIR") or (Path.home() / ".claude"))


def project_slug(path) -> str:
    return re.sub(r"[^A-Za-z0-9]", "-", str(Path(path).resolve()))


def est_tokens(text: str) -> int:
    return math.ceil(len(text) / 4)


def read_json(path, default=None):
    try:
        return json.loads(Path(path).read_text(encoding="utf-8"))
    except (OSError, ValueError):
        return default


def write_json(path, data) -> None:
    p = Path(path)
    p.parent.mkdir(parents=True, exist_ok=True)
    p.write_text(json.dumps(data, indent=2, ensure_ascii=False, sort_keys=True) + "\n", encoding="utf-8")


def parse_frontmatter(text: str) -> tuple[dict, str]:
    """Tolerant YAML subset: `key: value`, quoted values, `>`/`|` blocks, indented continuations."""
    lines = text.splitlines()
    if not lines or lines[0].strip() != "---":
        return {}, text
    end = None
    for i in range(1, len(lines)):
        if lines[i].strip() == "---":
            end = i
            break
    if end is None:
        return {}, text
    meta: dict = {}
    key = None
    buf: list[str] = []

    def flush() -> None:
        nonlocal key, buf
        if key is not None:
            meta[key] = " ".join(s.strip() for s in buf if s.strip()).strip()
        key, buf = None, []

    for raw in lines[1:end]:
        m = re.match(r"^([A-Za-z0-9_-]+):\s*(.*)$", raw)
        if m and not raw.startswith((" ", "\t")):
            flush()
            key = m.group(1)
            val = m.group(2).strip()
            buf = [] if val in (">", "|", ">-", "|-") else [val]
        elif key is not None:
            buf.append(raw)
    flush()
    for k, v in list(meta.items()):
        if len(v) >= 2 and v[0] == v[-1] and v[0] in "\"'":
            meta[k] = v[1:-1]
        elif v.lower() in ("true", "false"):
            meta[k] = v.lower() == "true"
    return meta, "\n".join(lines[end + 1:])


def mask_secrets(obj):
    """Deep copy with secret-looking values replaced by MASK. Never mutates the input."""
    if isinstance(obj, dict):
        out = {}
        for k, v in obj.items():
            if isinstance(k, str) and k in ("env", "headers") and isinstance(v, dict):
                out[k] = {ek: MASK for ek in v}
            elif isinstance(k, str) and SECRET_KEY_RE.search(k) and isinstance(v, (str, int, float)):
                out[k] = MASK
            else:
                out[k] = mask_secrets(v)
        return out
    if isinstance(obj, list):
        return [mask_secrets(x) for x in obj]
    if isinstance(obj, str) and SECRET_VALUE_RE.match(obj):
        return MASK
    return obj


def has_plaintext_secret(obj) -> bool:
    if isinstance(obj, dict):
        for k, v in obj.items():
            if isinstance(k, str) and SECRET_KEY_RE.search(k) and isinstance(v, str) and v and not v.startswith("${"):
                return True
            if has_plaintext_secret(v):
                return True
    elif isinstance(obj, list):
        return any(has_plaintext_secret(x) for x in obj)
    return False


def _cache_fallback(home: Path) -> list[dict]:
    found = []
    cache = home / "plugins" / "cache"
    if not cache.is_dir():
        return found
    for mp in sorted(p for p in cache.iterdir() if p.is_dir()):
        for plug in sorted(p for p in mp.iterdir() if p.is_dir()):
            versions = sorted(p for p in plug.iterdir() if p.is_dir())
            if versions:
                found.append({
                    "id": f"{plug.name}@{mp.name}",
                    "version": versions[-1].name,
                    "scope": "unknown",
                    "enabled": "unknown",
                    "installPath": str(versions[-1]),
                })
    return found


def load_plugin_list(home: Path, override: Path | None = None) -> tuple[list[dict], list[str]]:
    """Enabled plugins from `claude plugin list --json`, an override file, or the cache."""
    warnings: list[str] = []
    if override is not None:
        data = read_json(override)
        if isinstance(data, list):
            return data, warnings
        warnings.append(f"plugin list override unreadable: {override}")
    else:
        try:
            out = subprocess.run(["claude", "plugin", "list", "--json"], capture_output=True, text=True, timeout=30)
            if out.returncode == 0:
                data = json.loads(out.stdout)
                if isinstance(data, list):
                    return data, warnings
            warnings.append(f"claude plugin list failed (rc={out.returncode})")
        except (OSError, subprocess.SubprocessError, ValueError) as exc:
            warnings.append(f"claude plugin list unavailable: {exc}")
    warnings.append("plugin list taken from plugins/cache scan; enabled state unknown")
    return _cache_fallback(home), warnings
```

```python
#!/usr/bin/env python3
"""Scan every skill and slash command Claude Code would load, write inventory.json."""
from __future__ import annotations

import argparse
import re
import sys
from datetime import datetime, timezone
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))
from common import DESC_LIMIT, claude_home, est_tokens, load_plugin_list, parse_frontmatter, write_json  # noqa: E402

FIRST_ACTION_RE = re.compile(
    r"(?i)(before any (?:response|action|other)|before (?:you |starting |doing )?anything|mandatory prerequisite"
    r"|must (?:be )?(?:invoked?|loaded?|called?|read)\b.{0,60}\bbefore\b|read (?:this )?(?:first|before)|call .{0,40}\bfirst\b)"
)
SLASH_RE = re.compile(r"(?<![\w/])/([a-z0-9][\w:-]{2,})")
BACKTICK_RE = re.compile(r"`([a-z0-9][\w:-]{2,})`")


def _entry(md: Path, source: str, slash: str, kind: str) -> dict:
    text = md.read_text(encoding="utf-8", errors="replace")
    meta, body = parse_frontmatter(text)
    desc = str(meta.get("description", "")).strip()
    if meta.get("when_to_use"):
        desc = (desc + " " + str(meta["when_to_use"])).strip()
    if not desc and kind == "command":
        stripped = body.strip()
        desc = stripped.splitlines()[0].strip() if stripped else ""
    name = str(meta.get("name") or (md.parent.name if kind == "skill" else md.stem))
    return {
        "name": name,
        "kind": kind,
        "source": source,
        "path": str(md),
        "slash_names": [slash],
        "description": desc,
        "desc_chars": len(desc),
        "est_tokens": est_tokens(desc),
        "truncated": len(desc) > DESC_LIMIT,
        "body_lines": body.count("\n") + 1 if body else 0,
        "mentions_skills": [],
        "first_action_claim": bool(FIRST_ACTION_RE.search(body)),
        "disable_model_invocation": meta.get("disable-model-invocation") is True,
        "user_invocable": meta.get("user-invocable") is not False,
        "has_scripts": (md.parent / "scripts").is_dir() if kind == "skill" else False,
        "has_references": (md.parent / "references").is_dir() if kind == "skill" else False,
        "enabled": True,
        "_raw_mentions": sorted(set(SLASH_RE.findall(body) + BACKTICK_RE.findall(body))),
    }


class Scanner:
    def __init__(self) -> None:
        self.entries: list[dict] = []
        self.seen: set[str] = set()
        self.scanned: list[str] = []
        self.warnings: list[str] = []

    def add(self, entry: dict) -> None:
        if entry["path"] in self.seen:
            return
        self.seen.add(entry["path"])
        self.entries.append(entry)

    def skills_dir(self, root: Path, source: str, prefix: str) -> None:
        if not root.is_dir():
            return
        self.scanned.append(str(root))
        for md in sorted(root.glob("*/SKILL.md")):
            self.add(_entry(md, source, f"/{prefix}{md.parent.name}", "skill"))

    def commands_dir(self, root: Path, source: str, prefix: str) -> None:
        if not root.is_dir():
            return
        self.scanned.append(str(root))
        for md in sorted(root.glob("*.md")):
            self.add(_entry(md, source, f"/{prefix}{md.stem}", "command"))

    def plugin_root(self, root: Path, source: str, short: str) -> None:
        self.skills_dir(root / "skills", source, f"{short}:")
        self.commands_dir(root / "commands", source, f"{short}:")

    def personal_skills(self, home: Path) -> None:
        root = home / "skills"
        if not root.is_dir():
            return
        self.scanned.append(str(root))
        for d in sorted(p for p in root.iterdir() if p.is_dir()):
            if (d / "SKILL.md").is_file():
                self.add(_entry(d / "SKILL.md", "personal", f"/{d.name}", "skill"))
            elif (d / "skills").is_dir():
                self.plugin_root(d, f"plugin:{d.name}@skills-dir", d.name)


def main() -> int:
    ap = argparse.ArgumentParser(description=__doc__)
    ap.add_argument("--project", required=True)
    ap.add_argument("--claude-home", default=None)
    ap.add_argument("--plugin-list", default=None, help="JSON file used instead of `claude plugin list --json`")
    ap.add_argument("--extra", action="append", default=[], help="candidate skill dir or plugin root, scanned as source=candidate")
    ap.add_argument("--out", required=True)
    a = ap.parse_args()

    home = Path(a.claude_home).resolve() if a.claude_home else claude_home()
    project = Path(a.project).resolve()
    sc = Scanner()

    sc.personal_skills(home)
    sc.skills_dir(project / ".claude" / "skills", "project", "")
    sc.commands_dir(home / "commands", "command:user", "")
    sc.commands_dir(project / ".claude" / "commands", "command:project", "")

    plugins, warnings = load_plugin_list(home, Path(a.plugin_list) if a.plugin_list else None)
    sc.warnings.extend(warnings)
    for p in plugins:
        if p.get("enabled") is False:
            continue
        pid = str(p.get("id", "?"))
        root = Path(str(p.get("installPath", "")))
        if not root.is_dir():
            sc.warnings.append(f"installPath missing for {pid}: {root}")
            continue
        before = len(sc.entries)
        sc.plugin_root(root, f"plugin:{pid}", pid.split("@")[0])
        if p.get("enabled") == "unknown":
            for e in sc.entries[before:]:
                e["enabled"] = "unknown"

    for x in a.extra:
        root = Path(x).resolve()
        if (root / "SKILL.md").is_file():
            sc.add(_entry(root / "SKILL.md", "candidate", f"/{root.name}", "skill"))
        else:
            sc.plugin_root(root, f"candidate:{root.name}", root.name)

    names = {e["name"] for e in sc.entries}
    slash_to_name = {s.lstrip("/"): e["name"] for e in sc.entries for s in e["slash_names"]}
    for e in sc.entries:
        found = set()
        for tok in e.pop("_raw_mentions"):
            bare = tok.split(":")[-1]
            if tok in slash_to_name and slash_to_name[tok] != e["name"]:
                found.add(slash_to_name[tok])
            elif bare in names and bare != e["name"]:
                found.add(bare)
        e["mentions_skills"] = sorted(found)

    by_name: dict[str, list[str]] = {}
    for e in sc.entries:
        by_name.setdefault(e["name"], []).append(e["source"])
    same_name = {n: sorted(s) for n, s in by_name.items() if len(s) > 1}

    write_json(a.out, {
        "generated_at": datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ"),
        "project": str(project),
        "claude_home": str(home),
        "entries": sc.entries,
        "same_name": same_name,
        "est_listing_tokens": sum(e["est_tokens"] for e in sc.entries if not e["disable_model_invocation"]),
        "sources_scanned": sc.scanned,
        "warnings": sc.warnings,
    })
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
#!/usr/bin/env python3
"""Count Skill invocations, slash commands and MCP tool calls in Claude Code transcripts.

The transcript format is undocumented and may change; this script fails soft.
"""
from __future__ import annotations

import argparse
import json
import re
import sys
import time
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))
from common import claude_home, write_json  # noqa: E402

CMD_RE = re.compile(r"<command-name>([^<]+)</command-name>")


def bump(table: dict, key: str, slug: str) -> None:
    row = table.setdefault(key, {"total": 0, "by_project": {}})
    row["total"] += 1
    row["by_project"][slug] = row["by_project"].get(slug, 0) + 1


def scan_file(path: Path, slug: str, acc: dict, stats: dict) -> None:
    with path.open(encoding="utf-8", errors="replace") as fh:
        for line in fh:
            if "<command-name>" in line:
                for c in CMD_RE.findall(line):
                    bump(acc["slash"], c.strip(), slug)
            if '"tool_use"' not in line:
                continue
            try:
                rec = json.loads(line)
            except ValueError:
                stats["bad_lines"] += 1
                continue
            msg = rec.get("message") if isinstance(rec, dict) else None
            content = msg.get("content") if isinstance(msg, dict) else None
            if not isinstance(content, list):
                continue
            for block in content:
                if not isinstance(block, dict) or block.get("type") != "tool_use":
                    continue
                stats["tool_uses"] += 1
                name = str(block.get("name", ""))
                if name == "Skill":
                    skill = (block.get("input") or {}).get("skill")
                    if skill:
                        bump(acc["skills"], str(skill), slug)
                elif name.startswith("mcp__"):
                    parts = name.split("__")
                    if len(parts) >= 2 and parts[1]:
                        bump(acc["mcp_servers"], parts[1], slug)


def main() -> int:
    ap = argparse.ArgumentParser(description=__doc__)
    ap.add_argument("--projects-dir", default=None, help="defaults to <claude-home>/projects")
    ap.add_argument("--claude-home", default=None)
    ap.add_argument("--since", type=int, default=30, help="days; files older than this are skipped")
    ap.add_argument("--out", required=True)
    a = ap.parse_args()

    home = Path(a.claude_home).resolve() if a.claude_home else claude_home()
    projects = Path(a.projects_dir).resolve() if a.projects_dir else home / "projects"
    cutoff = time.time() - a.since * 86400
    acc = {"skills": {}, "slash": {}, "mcp_servers": {}}
    stats = {"files": 0, "tool_uses": 0, "bad_lines": 0}
    warnings: list[str] = []

    if not projects.is_dir():
        warnings.append(f"projects dir not found: {projects}")
    else:
        for f in sorted(projects.rglob("*.jsonl")):
            try:
                if f.stat().st_mtime < cutoff:
                    continue
            except OSError:
                continue
            slug = f.relative_to(projects).parts[0]
            stats["files"] += 1
            try:
                scan_file(f, slug, acc, stats)
            except OSError as exc:
                warnings.append(f"unreadable {f}: {exc}")

    status = "ok"
    if stats["files"] > 0 and stats["tool_uses"] == 0:
        status = "unavailable"
        warnings.append("no tool_use records parsed; transcript format may have changed. Ask the user to run /skill-doctor instead.")
    elif stats["files"] == 0:
        status = "unavailable"
        warnings.append("no transcripts in window; run /skill-doctor for usage.")

    write_json(a.out, {
        "status": status,
        "since_days": a.since,
        "files_scanned": stats["files"],
        "tool_uses_seen": stats["tool_uses"],
        "bad_lines": stats["bad_lines"],
        "skills": acc["skills"],
        "slash": acc["slash"],
        "mcp_servers": acc["mcp_servers"],
        "warnings": warnings,
    })
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
#!/usr/bin/env python3
"""Merge hooks and MCP servers from every scope, flag overlaps and duplicates, mask secrets."""
from __future__ import annotations

import argparse
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))
from common import claude_home, has_plaintext_secret, load_plugin_list, mask_secrets, read_json, write_json  # noqa: E402

PROJECT_TOOL_WORDS = ("pnpm", "npm ", "npx ", "yarn", "bun ", "pytest", "cargo ", "go test", "make ", "gradle", "mvn ")


def collect_hooks(cfg, source: str, hooks: dict) -> None:
    if not isinstance(cfg, dict):
        return
    table = cfg.get("hooks") if isinstance(cfg.get("hooks"), dict) else None
    if table is None and any(isinstance(v, list) for v in cfg.values()) and "modules" not in cfg:
        table = cfg  # bare {Event: [...]} form
    if isinstance(table, dict):
        for event, groups in table.items():
            if not isinstance(groups, list):
                continue
            for g in groups:
                if not isinstance(g, dict):
                    continue
                matcher = g.get("matcher") or "*"
                for h in g.get("hooks") or []:
                    if not isinstance(h, dict):
                        continue
                    hooks.setdefault(event, []).append({
                        "source": source,
                        "matcher": matcher,
                        "type": h.get("type", "command"),
                        "command": str(h.get("command") or h.get("module") or h.get("prompt") or ""),
                    })
    mods = cfg.get("modules")
    if isinstance(mods, list):
        hooks.setdefault("(mod modules)", []).extend(
            {"source": source, "matcher": "*", "type": "module", "command": str(m)} for m in mods
        )


def collect_mcp(cfg, source: str, mcp: list) -> None:
    servers = cfg.get("mcpServers") if isinstance(cfg, dict) else None
    if not isinstance(servers, dict):
        return
    for name, spec in servers.items():
        if not isinstance(spec, dict):
            continue
        if spec.get("url"):
            kind = spec.get("type") or "http"
            key = "url:" + str(spec["url"]).rstrip("/")
        else:
            kind = spec.get("type") or "stdio"
            key = "cmd:" + " ".join([str(spec.get("command", ""))] + [str(x) for x in spec.get("args") or []])
        mcp.append({
            "name": str(name),
            "source": source,
            "kind": kind,
            "key": key,
            "has_plaintext_secret": has_plaintext_secret(spec),
            "spec": mask_secrets(spec),
        })


def plugin_hooks(root: Path, source: str, hooks: dict, warnings: list) -> None:
    hj = read_json(root / "hooks" / "hooks.json")
    if hj is not None:
        collect_hooks(hj, source, hooks)
    pj = read_json(root / ".claude-plugin" / "plugin.json") or {}
    h = pj.get("hooks") if isinstance(pj, dict) else None
    if isinstance(h, dict):
        collect_hooks(h, source, hooks)
    elif isinstance(h, str):
        inline = read_json(root / h)
        if inline is None:
            warnings.append(f"{source}: hooks file not readable: {h}")
        else:
            collect_hooks(inline, source, hooks)


def main() -> int:
    ap = argparse.ArgumentParser(description=__doc__)

    ap.add_argument("--claude-home", default=None)

    mcp: list = []

        ("user settings", home / "settings.json"),
        ("user settings.local", home / "settings.local.json"),
        ("project settings", project / ".claude" / "settings.json"),
        ("project settings.local", project / ".claude" / "settings.local.json"),
    ]
    for label, path in settings_files:
        cfg = read_json(path)
        if cfg is not None:
            collect_hooks(cfg, f"{label} ({path})", hooks)

    dot_claude_json = next((p for p in (home / ".claude.json", Path.home() / ".claude.json") if p.is_file()), None)
    if dot_claude_json is not None:
        cfg = read_json(dot_claude_json) or {}
        collect_mcp(cfg, "~/.claude.json", mcp)
        proj_cfg = (cfg.get("projects") or {}).get(str(project)) if isinstance(cfg, dict) else None
        if isinstance(proj_cfg, dict):
            collect_mcp(proj_cfg, f"~/.claude.json projects[{project}]", mcp)
    for label, path in (("~/.claude/.mcp.json", home / ".mcp.json"), ("project .mcp.json", project / ".mcp.json")):
        cfg = read_json(path)
        if cfg is not None:
            collect_mcp(cfg, label, mcp)

    plugins, w = load_plugin_list(home, Path(a.plugin_list) if a.plugin_list else None)
    warnings.extend(w)
    for p in plugins:
        if p.get("enabled") is False:
            continue
        root = Path(str(p.get("installPath", "")))
        if not root.is_dir():
            continue
        src = f"plugin:{p.get('id', '?')}"
        plugin_hooks(root, src, hooks, warnings)
        cfg = read_json(root / ".mcp.json")
        if cfg is not None:
            collect_mcp(cfg, src, mcp)

    for x in a.extra:
        root = Path(x).resolve()
        src = f"candidate:{root.name}"
        plugin_hooks(root, src, hooks, warnings)
        cfg = read_json(root / ".mcp.json")
        if cfg is not None:
            collect_mcp(cfg, src, mcp)

    overlaps = []
    for event, rows in hooks.items():
        by_matcher: dict[str, list[str]] = {}
        for r in rows:
            by_matcher.setdefault(r["matcher"], []).append(r["source"])
        for matcher, sources in by_matcher.items():
            uniq = sorted(set(sources))
            if len(uniq) > 1:
                overlaps.append({"event": event, "matcher": matcher, "sources": uniq})

    suspicious = []
    for event, rows in hooks.items():
        for r in rows:
            if r["source"].startswith("user settings") and any(w_ in r["command"] for w_ in PROJECT_TOOL_WORDS):
                suspicious.append({"source": r["source"], "event": event, "command": r["command"],
                                   "why": "project tool in user scope runs in every repo"})

    by_key: dict[str, list[dict]] = {}
    by_name: dict[str, list[str]] = {}
    for m in mcp:
        by_key.setdefault(m["key"], []).append({"name": m["name"], "source": m["source"]})
        by_name.setdefault(m["name"], []).append(m["source"])
    duplicates = [{"key": k, "entries": v} for k, v in sorted(by_key.items()) if len(v) > 1]
    same_name = [{"name": n, "sources": sorted(s)} for n, s in sorted(by_name.items()) if len(s) > 1]

    write_json(a.out, {
        "hooks": hooks,
        "hook_overlaps": overlaps,
        "suspicious_global_hooks": suspicious,
        "mcp": mcp,
        "mcp_duplicates": duplicates,
        "mcp_same_name": same_name,
        "warnings": warnings,
    })
    return 0

    sys.exit(main())
```

```python
#!/usr/bin/env python3
"""Group inventory entries that plausibly compete for the same prompts."""
from __future__ import annotations

import argparse
import re
import sys
from itertools import combinations
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))
from common import read_json, write_json  # noqa: E402

STOP = set(
    "a an the and or of to for in on with by from as is are be been use used using uses when this that it its "
    "your you any all skill skills tool tools file files user users claude code run runs runs into via not no "
    "do does if then than so such per new one two also can will should must may into about after before "
    "what which who how where why their they them these those".split()
)
OVERSIZE = 20


def key_of(e: dict, dup_names: set) -> str:
    return f"{e['name']}@{e['source']}" if e["name"] in dup_names else e["name"]


def desc_tokens(e: dict) -> set:
    text = f"{e['name'].replace('-', ' ')} {e.get('description', '')}".lower()
    return {t for t in re.split(r"[^a-z0-9]+", text) if len(t) >= 3 and t not in STOP}


def name_tokens(e: dict) -> set:
    bare = e["name"].split(":")[-1]
    return {t for t in bare.split("-") if len(t) >= 4 and t not in STOP}


def jaccard(a: set, b: set) -> float:
    return len(a & b) / len(a | b) if a | b else 0.0


class UnionFind:
    def __init__(self, keys):
        self.parent = {k: k for k in keys}

    def find(self, k):
        while self.parent[k] != k:
            self.parent[k] = self.parent[self.parent[k]]
            k = self.parent[k]
        return k

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra != rb:
            self.parent[rb] = ra


def main() -> int:
    ap = argparse.ArgumentParser(description=__doc__)
    ap.add_argument("--inventory", required=True)
    ap.add_argument("--threshold", type=float, default=0.15)
    ap.add_argument("--out", required=True)
    a = ap.parse_args()

    inv = read_json(a.inventory) or {}
    entries = [e for e in inv.get("entries", []) if not e.get("disable_model_invocation")]
    counts: dict[str, int] = {}
    for e in entries:
        counts[e["name"]] = counts.get(e["name"], 0) + 1
    dup_names = {n for n, c in counts.items() if c > 1}
    keyed = {key_of(e, dup_names): e for e in entries}
    uf = UnionFind(keyed.keys())
    reasons: dict[str, list[str]] = {}
    pair_scores: dict[tuple[str, str], float] = {}

    def link(x: str, y: str, why: str) -> None:
        uf.union(x, y)
        reasons.setdefault(x, []).append(why)

    dtok = {k: desc_tokens(e) for k, e in keyed.items()}
    ntok = {k: name_tokens(e) for k, e in keyed.items()}
    for x, y in combinations(sorted(keyed), 2):
        j = jaccard(dtok[x], dtok[y])
        pair_scores[(x, y)] = round(j, 3)
        if j >= a.threshold:
            link(x, y, f"jaccard {j:.2f}: {x} ~ {y}")
        shared = ntok[x] & ntok[y]
        if shared:
            link(x, y, f"name token '{sorted(shared)[0]}': {x} ~ {y}")
        if keyed[x]["name"] == keyed[y]["name"]:
            link(x, y, f"same name across scopes: {x} ~ {y}")

    by_name = {}
    for k, e in keyed.items():
        by_name.setdefault(e["name"], []).append(k)
    for k, e in keyed.items():
        for m in e.get("mentions_skills", []):
            for other in by_name.get(m, []):
                if other != k:
                    link(k, other, f"mentions: {k} -> {other}")

    groups: dict[str, list[str]] = {}
    for k in keyed:
        groups.setdefault(uf.find(k), []).append(k)

    clusters, singletons, oversized = [], [], []
    for i, members in enumerate(sorted((sorted(m) for m in groups.values()), key=lambda m: m[0]), start=1):
        if len(members) == 1:
            singletons.append(members[0])
            continue
        why = sorted({r for m in members for r in reasons.get(m, [])})
        pairs = sorted(
            ({"a": x, "b": y, "jaccard": pair_scores[(x, y)]} for x, y in combinations(members, 2)),
            key=lambda p: -p["jaccard"],
        )[:10]
        cid = f"c{i:02d}"
        clusters.append({
            "id": cid,
            "members": members,
            "sources": sorted({keyed[m]["source"] for m in members}),
            "reasons": why,
            "pairs": pairs,
        })
        if len(members) > OVERSIZE:
            oversized.append(cid)

    write_json(a.out, {"threshold": a.threshold, "clusters": clusters, "singletons": sorted(singletons), "oversized": oversized})
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
#!/usr/bin/env python3
"""Flag weak skill descriptions: too long, too short, no trigger, no exclusion, overbroad, unused."""
from __future__ import annotations

import argparse
import re
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))
from common import DESC_LIMIT, read_json, write_json  # noqa: E402

TRIGGER_RE = re.compile(r"(?i)\b(use (?:this )?(?:skill )?(?:when|for|whenever)|trigger|when the user|whenever|invoke when|use when|run when)\b")
NOT_FOR_RE = re.compile(r"(?i)\b(not for|do not use|don't use|never (?:use|for)|not when|skip when|instead of|except)\b")
BROAD_RE = re.compile(r"(?i)\b(any|anything|everything|all|every)\b")
NEAR_LIMIT = 1200
TOO_SHORT = 60


def uses_for(e: dict, usage: dict) -> int:
    keys = {e["name"]} | {s.lstrip("/") for s in e.get("slash_names", [])}
    src = e.get("source", "")
    if src.startswith("plugin:"):
        keys.add(f"{src[len('plugin:'):].split('@')[0]}:{e['name']}")
    total = 0
    for k in keys:
        total += (usage.get("skills", {}).get(k) or {}).get("total", 0)
        total += (usage.get("slash", {}).get("/" + k) or {}).get("total", 0)
    return total


def lint(e: dict, usage: dict, usage_ok: bool) -> list[str]:
    desc = e.get("description", "")
    n = len(desc)
    issues = []
    if n == 0:
        issues.append("empty")
    elif n < TOO_SHORT:
        issues.append("too_short")
    if n > DESC_LIMIT:
        issues.append("truncated_over_1536")
    elif n > NEAR_LIMIT:
        issues.append("near_limit")
    if n and not TRIGGER_RE.search(desc):
        issues.append("no_trigger_phrase")
    if n and not NOT_FOR_RE.search(desc):
        issues.append("no_not_for")
    if n and BROAD_RE.search(desc) and not NOT_FOR_RE.search(desc):
        issues.append("overbroad")
    if usage_ok and uses_for(e, usage) == 0:
        issues.append("never_used_in_window")
    if e.get("first_action_claim"):
        issues.append("claims_first_action")
    return issues


def main() -> int:
    ap = argparse.ArgumentParser(description=__doc__)
    ap.add_argument("--inventory", required=True)
    ap.add_argument("--usage", required=True)
    ap.add_argument("--out", required=True)
    a = ap.parse_args()

    inv = read_json(a.inventory) or {}
    usage = read_json(a.usage) or {}
    usage_ok = usage.get("status") == "ok"
    rows, summary = [], {}
    for e in inv.get("entries", []):
        issues = lint(e, usage, usage_ok)
        if not issues:
            continue
        for i in issues:
            summary[i] = summary.get(i, 0) + 1
        rows.append({"name": e["name"], "source": e["source"], "desc_chars": e.get("desc_chars", 0),
                     "uses": uses_for(e, usage) if usage_ok else None, "issues": issues})
    rows.sort(key=lambda r: (-len(r["issues"]), r["name"]))
    write_json(a.out, {"usage_status": usage.get("status", "unknown"), "summary": summary, "entries": rows})
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```bash
# Run every skillkit scan into one output directory (bash 3.2 compatible).
# Usage: run.sh --project <dir> --out <dir> [--since <days>] [--claude-home <dir>] [--plugin-list <json>] [--extra <dir>]...
set -euo pipefail
HERE="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
PROJECT=""; OUT=""; SINCE=30
HOME_ARGS=(); PL_ARGS=(); EXTRA=()
while [ $# -gt 0 ]; do
  case "$1" in
    --project) PROJECT="$2"; shift 2 ;;
    --out) OUT="$2"; shift 2 ;;
    --since) SINCE="$2"; shift 2 ;;
    --claude-home) HOME_ARGS=(--claude-home "$2"); shift 2 ;;
    --plugin-list) PL_ARGS=(--plugin-list "$2"); shift 2 ;;
    --extra) EXTRA+=(--extra "$2"); shift 2 ;;
    *) echo "unknown argument: $1" >&2; exit 2 ;;
  esac
done
if [ -z "$PROJECT" ] || [ -z "$OUT" ]; then
  echo "usage: run.sh --project <dir> --out <dir> [--since N] [--claude-home DIR] [--plugin-list FILE] [--extra DIR]" >&2
  exit 2
fi
mkdir -p "$OUT"
python3 -I "$HERE/inventory.py" --project "$PROJECT" --out "$OUT/inventory.json" \
  ${HOME_ARGS[@]+"${HOME_ARGS[@]}"} ${PL_ARGS[@]+"${PL_ARGS[@]}"} ${EXTRA[@]+"${EXTRA[@]}"}
```

```markdown
# Conflict taxonomy

Every finding gets exactly one class. Classes R, C and X need a subagent verdict; the rest are decided by script output alone.

| class | name | what it means | decided by | action |
|---|---|---|---|---|
| R | redundant | Same job, same kind of output. Loading both only adds a coin flip. | subagent | keep one; disable or uninstall the rest |
| C | complementary | Neighbouring jobs: different phase, scope, or target. Both earn their place. | subagent | one routing line per situation in CLAUDE.md |
| X | contradictory | When both are loaded, their bodies give opposite orders (ask vs do not ask, push vs never push, verbose vs terse, two "I must run first" claims). | subagent, checked against CLAUDE.md and the output style | state precedence in CLAUDE.md, or disable one |
| S | shadow / cross-scope duplicate | Same bare name in two scopes. Personal beats project (project copy never loads). Plugin skills are namespaced, so a vendored copy and the plugin both load. | `inventory.same_name` | delete the copy that never loads; pick plugin or vendored, not both |
| H | hook / policy | Two sources hook the same event and matcher; a plugin policy blocks another plugin's hook; a user-scope hook runs a project tool in every repo. | `hooks_mcp.hook_overlaps`, `suspicious_global_hooks` | move the hook to project scope; whitelist; drop one |
| M | MCP duplicate | Same server registered twice (same URL or command) or same name from two sources. | `hooks_mcp.mcp_duplicates`, `mcp_same_name` | remove one registration; rotate any plaintext secret |
| D | dead weight | Zero uses in the window across Skill tool, slash and MCP calls. | `desc_lint` issue `never_used_in_window`, `usage.mcp_servers` | review list only; project-scoped skills fire in one repo, hooks-driven skills never show as uses |
| P | misplaced scope | A personal skill used in one project only, or a plugin loaded in a project that never uses it. | `usage.*.by_project` vs inventory | move to `<repo>/.claude/skills`; `enabledPlugins` per project |
| Q | description quality | Over 1,536 chars (cut), under 60 (vague), no trigger phrase, no "not for", broad words with no exclusion. | `desc_lint` | propose a new description |

## Verdict rules for the subagent

- R only when one member fully covers the other's job. If either does something the other cannot, it is C.
- X requires a quotable sentence from each side. A difference in tone is not X.
- Usage counts are evidence, never the verdict. A zero-use member is a drop candidate only when another member covers its job.
- "none" is allowed: coincidental word overlap with different jobs.

## Severity for the report order

1. X with CLAUDE.md or the output style (behaviour flips every turn)
2. M with a plaintext secret
3. H overlaps on PreToolUse / UserPromptSubmit
4. R
5. S
6. P, then D, then Q
```
